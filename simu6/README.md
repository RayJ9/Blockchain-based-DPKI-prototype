# DPKI上界面与PKI面交线计算结果

## 项目概述
本项目实现了DPKI上界面与PKI面的交线计算和可视化，通过遍历每个ts值找到两个面最接近的点，并连成一条完整的交线。

## 文件说明

### 核心文件
- `plot_3d_matlab.m` - 主要的MATLAB脚本，包含完整的3D可视化和交线计算逻辑
- `surface_data_matrices.npz` - 包含PKI和DPKI面数据的NumPy数组文件

### 输出文件
- `figure10_dpki_3d_final.fig` - MATLAB图形文件
- `figure10_dpki_3d_final.png` - PNG格式图片
- `figure10_dpki_3d_final.eps` - EPS格式矢量图

## 技术实现

### 交线计算算法
1. **遍历ts值**: 对每个ts值（50个点，范围0.5-1.0）
2. **寻找最接近点**: 在pf范围0.2-0.8内，计算PKI与DPKI上界的差值绝对值
3. **选择最优点**: 选择差值最小的点作为该ts值下的交线点
4. **排序连线**: 按ts值排序所有交点，用紫色细线连接

### 关键参数
- **交线点数**: 50个点
- **ts范围**: 0.5 - 1.0
- **pf范围**: 0.2 - 0.8（严格限制）
- **平均差值**: 0.0035（非常接近）
- **线条颜色**: 紫色 [0.6, 0.2, 0.8]
- **线条宽度**: 2（适中粗细）

### 可视化特性
- PKI面：半透明橙色
- DPKI上界：蓝色线条
- DPKI下界：橙色线条
- DPKI区域：半透明蓝色填充
- 交线：紫色细线（无标记点）
