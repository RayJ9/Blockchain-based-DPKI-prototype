# Fig9

Availability figure for failure probability and timeout threshold.

The current source data are rebuilt from Fig7-style per-request service-time
samples by running:

```powershell
python ..\build_fig9_fig10_from_fig7_service.py
```

For Fig9, the PKI curve is plotted as a finite-sample conservative estimate
over 10000 requests at each grid point. The source CSV keeps both `PKI_Exact`
and `PKI_Observed` for checking.

Run:

```powershell
python generate_data_fig9.py
& 'C:\Program Files\MATLAB\R2024a\bin\matlab.exe' -batch "cd('fig9'); plot_fig9"
```

Outputs:

- `figure.png`
- `figure.pdf`
- `figure.eps`

The EPS is generated by `convert_png_to_pdf_eps.py` from the PNG to keep
transparent 3-D surfaces consistent across formats.

Kept data:

- `data_fig9.mat`
- `figure_summary.csv`
- `source_data/fig7_service_latency_samples_summary.csv`
- `source_data/surface_data_matrices_responding.npz`
- `source_data/surface_data_matrices_malicious.npz`
