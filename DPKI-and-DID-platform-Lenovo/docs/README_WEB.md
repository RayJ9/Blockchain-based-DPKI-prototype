# DPKI Web管理平台使用说明

## 概述

DPKI Web管理平台是基于原有命令行DPKI系统开发的Web界面版本，提供了友好的图形化操作界面，让用户可以通过浏览器轻松管理分布式公钥基础设施。

## 功能特性

### 1. 服务器管理
- **启动/停止CA服务器**: 控制证书颁发机构服务器
- **启动/停止UE服务器**: 控制用户实体服务器
- **实时状态监控**: 显示服务器运行状态

### 2. CA端功能
- **初始化根证书**: 生成并上链根CA证书
- **签署证书**: 为UE签发数字证书
- **更新证书**: 更新已签发的证书
- **撤销证书**: 撤销无效或过期的证书

### 3. UE端功能
- **发起CSR请求**: 生成证书签名请求并发送给CA
- **更新地址列表**: 同步其他UE的网络地址信息
- **UE间认证**: 发起点对点身份认证请求

### 4. 系统监控
- **实时日志**: 显示系统操作日志和状态信息
- **状态指示**: 直观显示各组件运行状态

## 安装和启动

### 1. 安装依赖
```bash
npm install
```

### 2. 启动Web服务器
```bash
npm run web
# 或者
npm start
# 或者
node web-server.js
```

### 3. 访问管理界面
打开浏览器访问: `http://localhost:3001`

## 使用流程

### 初始化系统
1. **启动服务器**
   - 点击"启动 CA 服务器"
   - 点击"启动 UE 服务器"
   - 确认状态指示器显示"在线"

2. **初始化根证书**
   - 在CA端功能区域填写CA名称和标签
   - 点击"初始化根证书"
   - 等待操作完成

### 证书管理流程
1. **UE发起证书请求**
   - 在UE端功能区域填写UE名称
   - 点击"发起CSR请求"

2. **CA签署证书**
   - 在CA端功能区域填写CA名称和UE名称
   - 点击"签署证书"

3. **证书更新（可选）**
   - 填写相应的CA名称和UE名称
   - 点击"更新证书"

4. **证书撤销（可选）**
   - 填写要撤销的UE名称
   - 点击"撤销证书"

### UE间认证
1. **更新地址列表**
   - 点击"更新地址列表"确保有最新的UE信息

2. **发起认证请求**
   - 填写本地UE名称和目标UE名称
   - 点击"发起认证请求"
   - 系统将自动进行区块链验证

## 命令行对应关系

Web界面功能与原命令行的对应关系：

| Web功能 | 原命令行 |
|---------|----------|
| 启动CA服务器 | `./Server-CA` |
| 启动UE服务器 | `./Server-UE` |
| 初始化根证书 | `./DPKI-CA initial -ca_name <name> -ca_label <label>` |
| 签署证书 | `./DPKI-CA register -ca_name <ca> -ue_name <ue>` |
| 更新证书 | `./DPKI-CA update -ca_name <ca> -ue_name <ue>` |
| 撤销证书 | `./DPKI-CA revoke -ue_name <ue>` |
| 发起CSR请求 | `./DPKI-UE request -ue_name <name>` |
| 更新地址列表 | `./DPKI-UE updatelist` |
| UE间认证 | `./DPKI-UE authenticationreq -ue_name <ue> -target <target>` |

## 技术架构

### 前端
- **HTML5**: 结构化页面内容
- **CSS3**: 现代化响应式样式设计
- **JavaScript**: 交互逻辑和API调用

### 后端
- **Node.js**: 服务器运行环境
- **Express.js**: Web框架
- **CORS**: 跨域资源共享支持

### 通信
- **RESTful API**: 前后端数据交换
- **JSON**: 数据传输格式
- **WebSocket**: 实时状态更新（未来版本）

## 注意事项

1. **配置文件**: 确保`DPKI-config.json`配置正确
2. **区块链连接**: 确保区块链节点正常运行
3. **端口占用**: 默认使用3001端口，如有冲突请修改
4. **权限问题**: 在某些系统上可能需要管理员权限
5. **防火墙**: 确保相关端口未被防火墙阻止

## 故障排除

### 常见问题
1. **服务器启动失败**
   - 检查端口是否被占用
   - 确认可执行文件存在
   - 查看系统日志获取详细错误信息

2. **API请求失败**
   - 检查网络连接
   - 确认后端服务器正常运行
   - 查看浏览器控制台错误信息

3. **区块链操作失败**
   - 检查区块链节点状态
   - 确认账户余额充足
   - 验证智能合约地址正确

### 日志查看
- Web界面底部的系统日志区域显示实时操作信息
- 后端服务器控制台显示详细的系统日志
- 可以通过"清空日志"按钮清理界面日志

## 开发和扩展

### 添加新功能
1. 在`web-server.js`中添加新的API端点
2. 在`script.js`中添加前端调用逻辑
3. 在`index.html`中添加相应的UI元素
4. 在`styles.css`中添加样式定义

### 自定义样式
- 修改`styles.css`文件自定义界面外观
- 支持响应式设计，适配不同屏幕尺寸
- 使用CSS变量便于主题定制
