# Blockchain-Based DPKI Figure Package

This repository keeps the final paper figures and the files needed to replot
them from retained data.

Final figure folders:

- `fig3`
- `fig4`
- `Fig5-lambda`
- `Fig6-epsilon`
- `Fig7-p`
- `Fig8-M`
- `fig9`
- `fig10`

Each folder contains the final `figure.*` outputs, retained CSV/MAT/NPZ data,
and a local script for replotting that figure.

Private paper/editing folders are intentionally ignored by Git:

- `JIoT/`
- `response_letter/`
